# Design

Portable Agents executes trusted Lua/Markdown and transports opaque bytes. Zinc owns JSON requests, config, model protocols, state, retrieval, and tool execution. Connector owns Discord routing, credentials, controls, and rendering. Zinc is effectful: explicit config, stored state, and external replies determine its behavior; it is not a pure function.

A root call creates an actor-owned run and durable branch. Runs own the reported-token budget. Branches own attachment, inclusive history boundary, preset, temporary lifetime, and terminal response. Events own kind and text, not token counts. Failed durable branches remain auditable and eligible for actor-owned continuation. Automatic attachment is selected in the branch-creation transaction.

Quota counts provider-reported total tokens from completed chat and rerank requests. It is checked before each later request; final and already-running concurrent requests can overshoot. Source/result bytes have separate ceilings. Nested calls resolve the shared run through their caller event, cannot replace actor identity, and create temporary branches. Destruction removes an authorized temporary branch and its descendants.

Preset Markdown organizes instructions and visible capability implementations. Each capability table holds example strings in its array part and named Lua functions; `__tostring` renders examples and `__call` validates and dispatches operations. The first function argument is private tool grants. Preset metatables hold documents and permitted nested targets; preset `__tostring` combines documents and sorted capability descriptions. Runtime bindings derive fixed argument lists from those functions and seal the selected preset and caller event together. Configured roots, HTTP actions, and the search executable come from private config, not ambient home state. Nested presets can retain or reduce host authority. PA owns Imports separately; opaque config cannot create or replace an Import grant.

`zinc.md` composes ordinary named defaults, presets, documents, and the runtime. The presets are `unrestricted`, `configured`, and `empty`; `empty` has no host tools. `src/run.lua` owns the JSON boundary, config validation, named metadata members, model loop, branch lifecycle, Eval batches, and direct emissions. `src/store.lua` owns format-3 state, coordinates, quota, and short transactions. `src/memory.lua` owns actor-visible history, trigram spelling candidates, Cygnet expansion, and reranking. `src/model.lua` owns provider catalogs, exact reference resolution, HTTP/SSE parsing, usage normalization, and direct delta emissions. Filesystem and search implementations stay in their presets. Store's temporary per-event tokenizer also supplies bounded retrieval tokens; grounding runs before later appends replace those tokens. Store and Cygnet owners exist before statement preparation and share their normal close paths with initialization failures. The Eval capability view is built once per invocation.

No Store transaction spans model, host, Eval, process, or Import work. Completed JSON results carry coordinates and usage; JSON events identify branch and channel. Discord presentation does not belong to Zinc. `tostring` is for intentional descriptive text, not JSON serialization, source escaping, or private-config dumps. Ordinary source failures become tool results; call-level failures propagate with diagnostics rather than inventing results.
